# Nordsvar - naming brief and collision screening

## The name

"Nord" (Nordic identity) + "svar" (Danish for "answer") - the product literally answers
support calls. Reads calmly in Danish and pronounces cleanly internationally
("NORD-svar"). No AI/sparkle/Viking/flag cliches. Tagline: "Calm answers that stay
in-house." Chosen 2026-09-11 to replace the working name NordDesk, which collided with an
existing Danish office-furniture brand.

## Screening results (practical screening, NOT legal clearance)

Checked 2026-09-11 against public sources:

- Web: no company, product, or brand using "nordsvar" found. Only incidental running-text
  occurrences in Nordic Council / Norwegian Language Council reports (word fragments).
- Danish CVR: no company named Nordsvar.
- Trademark: no EUIPO/national trademark hits surfaced for "nordsvar".
- Domains verified unregistered at check time: nordsvar.com (Verisign RDAP 404),
  nordsvar.dk (whois.dk-hostmaster.dk: no entries), nordsvar.ai (whois.nic.ai: not
  found), nordsvar.io (Identity Digital RDAP 404).
- GitHub: user/org name "nordsvar" available (api.github.com/users/nordsvar -> 404).

### Rejected candidates and why

- Svar: SVAR UI component library (svar.dev) and svar.ai - same software space.
- Nordro: nordro.se is an enterprise software consulting firm.
- Trofast: IKEA TROFAST storage system + EU trademark filing.
- Vagt: saturated in Denmark (Vagt DK A/S, VAGT.DK ApS, vagtservices.com).
- Hvelv: existing "Hvelv" password-manager app on the App Store - same security space.
- Nordlyd: Danish CVR company "Nordlyd" plus the adjacent Norwegian health brand
  Nordlys AI crowds the nord-lyd/lys lane.
- Klarhed: Klarhed Consulting exists. Best runner-up but weaker for a support product.

## Caveats

This is practical screening from public sources, not a legal trademark search or legal
advice. Before going public: run a TMview/EUIPO check and register nordsvar.com/.dk/.ai/.io
plus the GitHub org/handle.
