# Nordsvar brand

The mark: rounded desk/screen tile in Nord Ink #10262E holding a five-bar voice waveform
in aurora teal (#2FBD96 -> #57D4B1), with a slim vertically-elongated north star in amber
#F2B441. Tile = on-premise four walls, waveform = voice support, star = calm Nordic
guidance. Deliberately no AI-sparkle, Viking, or flag cliches.

Wordmark: "Nordsvar" set in Noto Sans SemiBold, outlined to vector paths (the SVGs have
zero font dependency), single initial capital - one word, matching the merged
"nord + svar" construction. Tagline: "Calm answers that stay in-house."

## Assets

- mark.svg - app icon / avatar
- lockup-light.svg / lockup-dark.svg - horizontal lockups (outlined paths)
- mark-mono-ink.svg / mark-mono-white.svg - monochrome variants

## Rules

- On dark backgrounds the Ink tile merges into the background and the waveform + star
  float; use mark-mono-white where a single color is required.
- Clearspace: half the tile width on all sides. Minimum mark size: 16 px.
- Do not recolor the waveform, rotate the mark, or place it on busy imagery.
- Palette: Nord Ink #10262E, Mist #F6F8F7, Aurora #2FBD96 -> #57D4B1, Amber #F2B441.

See docs/NAMING.md for the naming rationale and collision screening.
